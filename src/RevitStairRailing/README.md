# RevitStairRailing (Ограждение лестниц)
Построение ограждений лестниц КМ из семейств «Каркас несущий», размещаемых по линии:
стойки, поручень, продольные прутки, опорные пластины и анкеры.

1. В окне выбираются типоразмеры элементов и размеры пролёта; схема пролёта перестраивается по введённым значениям.
2. После «Выбрать линии и построить» выбираются линии модели траектории — по краю маршей и площадок,
   одной цепочкой (или линии выбираются до запуска плагина).
3. Ограждение строится со смещением от линий влево или вправо по ходу подъёма и собирается в сборку
   «<имя>N» со следующим свободным номером.

# Сборка проекта
```
nuke compile --profile RevitStairRailing
```

# Публикация проекта
```
nuke publish --profile RevitStairRailing
```

# RevitVORChecker (Проверка ВОР)
Проверка BIM-моделей раздела КР перед выгрузкой ведомостей объёмов работ (ВОР, этап 3, стадия П):
пересечения, целостность объёмов, параметры СМР, материалы, армирование, сверка выгрузок ВОР (Excel).
Результат — «Реестр замечаний по контролю качества BIM-моделей» (.docx).

# Сборка проекта
```
nuke compile --profile RevitVORChecker
```

# Публикация проекта
```
nuke publish --profile RevitVORChecker
```
